# ReceiptIQ v2 — Real-Time Hybrid OCR & Instant Sync Package

## Included Files
- index.html (Complete PWA with Google Gemini Vision AI + Tesseract.js fallback OCR & JSONBin instant sync)
- manifest.json (PWA manifest)
- sw.js (Network-First Service Worker to prevent stale mobile caches)
- icon-192.png, icon-512.png, apple-touch-icon.png, favicon-32x32.png (Full icon pack)
- SETUP_GUIDE.md (This guide)

## Quick Setup
1. Upload all files to your GitHub Pages repository (`Expenselens`).
2. Get a free API key at https://aistudio.google.com/apikey, open ReceiptIQ -> Settings -> Real-Time Receipt OCR, paste it in, and tap Save API Key. It will automatically sync to Ashmita's phone via JSONBin.
